# 逐句精听

## 核心规则

浏览器拥有音频播放、速度、计时和正式作答。本地 Agent 只基于已提交 session 的材料事实，选择少量答案句做“预测 → 回放 → 对照 → 复述 → 重测”。不把倍速当作固定提分规则。

## 输入

1. 调用 `ielts_practice_read_session` 确认 session 已提交。
2. 调用 `ielts_practice_read_review({ sessionId, scope: "incorrect", includeMaterial: true })`。
3. 只选 1–3 道错题；没有转录、时间点或可用音频时，明确说明不能判断具体连读或发音原因。

## 单题循环

1. **先预测**：展示题干空格或问题，要求学习者先判断答案的词性、单复数、数字/日期或语义类别。
2. **短段回放**：让学习者在浏览器回放答案附近的短段，不先展示完整转录。
3. **证据对照**：只给必要的转录短句，比较用户作答与答案 key；标记真正可证实的错因，例如弱读、词界、拼写、改口干扰或语法形式。
4. **输出练习**：选择一个动作：跟读答案短语、拼写、区分单复数、标出改口词，或遮住文本复听。
5. **即时重测**：让学习者再次输入答案或复述短语；用 `again`、`hard`、`good` 描述本轮表现，但不要把它伪装成服务器诊断。

## 词汇收录

只从错题答案句提取 1–3 个可复用词块。用户明确要求保存后，调用 `ielts_vocabulary_add`，并传：

```text
sourceType: practice
sourceId: practice_session:<sessionId>
sourceTitle: <session title>
context: <必要的答案句片段>
```

不要自动把所有陌生词或整段转录写入词汇本。

## 输出

```text
本次精听：<题组与错题数>
先练：<题号与答案目标>
你先判断：<词性/形式预测>
浏览器回放：<短段操作>
对照后原因：<有证据的一项主因>
现在重测：<一个可回答动作>
```

若用户需要多题汇总，再转入“听力错题复盘”生成 Listening Error Notebook DOCX。
