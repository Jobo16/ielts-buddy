# 口语表达进入词汇本

口语反馈完成后，只有学习者明确提出“保存表达”“加入词汇本”或确认了候选清单，才写入个人词汇本。不要自动保存每次给出的自然表达，也不要把保存动作当作掌握。

## 候选选择

从本次真实回答或转写中选择 2–4 个可复用词块：

- 优先能帮助展开经历、表达原因、结果、对比或态度的自然口语块；
- 每项必须对应到学习者的一处原回答和本次给出的局部优化；
- 排除完整答案句、与本题绑定的专有名词和书面化过强的表达；
- 没有音频或转写证据时，不把发音问题转成词汇条目。

用户明确要求保存时，按该意图选择表达并保存；未要求保存时只展示建议。

## 确认后写入

调用 `ielts_vocabulary_add`，一次提交确认后的全部表达：

```json
{"kind":"word","items":[{"text":"allocate","meaning":"分配"}]}
```

释义由 Agent 提供；需要保存句子时使用 `kind="sentence"`。普通对话表达标记为“对话添加”；确实与本次已知题目关联时，可附上 `sourcePartId`。使用返回的词书或单词详情入口。

写入成功后只说明保存数量和表达名称。用户要练习时在对话中进行，词书工具不写回复习进度。
