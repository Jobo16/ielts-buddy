# 个人学习数据与证据

跨课程、练习和待办分析时，已授权 Agent 优先调用 `ielts_learner_export_data` 获取版本化只读快照；首次传 `{}`，已有完整缓存时传其 `dataVersion`。按 API origin 和 accountId 隔离本地缓存，读取 `summary`、`datasets` 和 `coverage` 后才分析需要的 records，不打印整包。`unchanged=true` 复用旧文件，返回新完整数据时整体替换；读取失败说明数据截至时间。快照不含题库全目录、未提交答案、聊天或媒体文件。不同集合可能重复描述同一次活动，不能直接相加。

刚完成的网页练习已经产生网站事件，不重复上报。用户提供的本地练习只可作为本轮观察；若确需保存学习证据，仅按当前开放的 `ielts_learning_push_events` 类型和用户意图提交，不能冒充网页评分或熟练度。自述目标、模型推断、任务打开状态都不是实测水平。
