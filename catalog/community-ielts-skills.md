## 维护口径

- 检索 GitHub 仓库搜索与代码搜索中的 `ielts`、`雅思`、`SKILL.md`，再用公开网页和 Skill 目录交叉核对。搜索覆盖 GitHub、常见 Skill 索引及其他代码托管平台；搜索索引和仓库内容会变化，因此这里是带日期的发现结果，不承诺囊括未来或未被索引的仓库。
- 正式表只列能找到学习相关 Skill 指令、且仓库有明确开源许可证的来源。普通雅思应用、仅用于开发该应用的 Skill、营销文案、没有 Skill 指令文件的项目，以及本仓库本身均不列入。
- 同一 Skill 的镜像、归档、vendor 副本单列。新增项目时提供仓库、具体 Skill 文件和许可证；若许可证尚不明确，先放入待核区。许可证或来源发生变化时按最新证据调整。
